## Code changes

FAQ uses native details/summary with a shared name for single-open behavior in supporting browsers. Older browsers can still open answers, potentially more than one. Removed its stateful client boundary. Footer and Alternatives are static server components; their existing Reveal wrappers remain small client islands. All five continuously animated definitions in Features now use whileInView, limiting their decorative animation to viewport intersections. This does not prove every hidden-by-opacity card has zero work, and it does not alter media playback logic. The orphan AudioWaveform component is not mounted on this site, so changing it would not have helped this release and it was left alone.

Vercel Analytics, PostHog, Meta attribution, recruitment integration, page destinations, pricing, metadata and FAQ answers remain unchanged. No extra tracking service was installed.
