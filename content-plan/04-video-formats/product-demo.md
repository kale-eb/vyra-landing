# Product demo

**A product demo video shows a product completing one real task from start to finish, with the screen or object large in frame and a voiceover naming what is happening and why it matters.**

## At a glance

| | |
| --- | --- |
| Best for | Launches, feature announcements, landing page video, sales follow-ups |
| Hook style | The end result first, then "here's how" |
| Pacing | 2-5 seconds per action, no waiting |
| Caption style | Phrase captions plus action labels |
| Music | Neutral, low, no vocals |
| Shot list | Clean screen recording at 60fps or product on a plain surface. Cursor or hands visible. Final result shot. Optional face for intro and outro. |
| Common mistakes | Showing every menu. Talking about features instead of the task. Tiny UI in a vertical frame. |

## Structure

- 0-3s: the result, the finished output
- 3-8s: what we're going to do, one sentence
- 8-60s: the task, action by action, each labeled
- 60-75s: the result again, with the time it took
- 75-85s: where to try it

## How to shoot it

- Script the task first. One task, five to eight steps.
- Record the screen at the highest resolution and 60fps.
- Move the cursor slowly and deliberately. You'll speed it up later.
- Hide notifications, clean the desktop, use realistic data.
- Record the voiceover after, matched to the recording.

## How to edit it

- Cut all loading, scrolling, and hesitation.
- Zoom into the region where the action happens, 150-200%.
- Add a short label for each action ("Add captions").
- Speed up any typing 2-3x.
- Return to full frame for the result.
- Keep the cursor visible and add a subtle click highlight.

## Prompt it in Vyra

> Turn this 8-minute screen recording into a 60-second demo of exporting a video. Cut every pause and loading screen, zoom into where I click on each step, and add a small label at the top for each step. Use my voiceover track and keep it clean, low music.

> Put the final exported video on screen for the first 3 seconds as the hook, then start the demo.

> Make a vertical version for Reels by reframing the screen recording around the cursor on each step.

## Variations

- Feature spotlight: one feature, 20 seconds.
- Founder demo: face intro, screen demo, face outro.
- Comparison demo: same task in two tools.
- Silent demo: on-screen labels only, for LinkedIn and X.

## FAQ

**Vertical or horizontal?**
Horizontal for landing pages and YouTube, vertical for social. Record horizontal at high resolution so a vertical reframe around the cursor is possible.

**How many steps should a demo show?**
Five to eight. If the task needs more, split it into two demos.

**Can Vyra reframe a horizontal screen recording to vertical?**
Yes. Ask it to follow the cursor or a named region and it crops and tracks the frame.
