**TikTok rewards volume and a strong first two seconds. Vyra gets you from raw clips to a captioned vertical cut in a few prompts, and lets you make five variations of the hook without rebuilding the edit.**

## Your three most-used prompts

Talking head cut:
```
Cut this into a 30-second 9:16 TikTok. Start on the line "nobody warns you about this", cut every pause over 0.4 seconds, filler words, and restarts. Word-by-word captions, bold white, slightly above center so they clear the bottom UI. No zooms or transitions.
```

Hook variations:
```
Make three versions of this edit that differ only in the first 3 seconds: one opens on the reveal shot, one opens on me saying the punchline, one opens on a text hook that says "I was wrong about this". Same everything else.
```

Trend recreation:
```
Match the attached reference: same cut timing to the sound, same caption placement, same text style. Use my clips only, keep my order.
```

## A typical workflow

1. Upload the clips and the sound if you are using one. Vyra transcribes speech and analyzes each clip.
2. Ask for the cut with the hook line, the target length, and the caption style in one message.
3. Check the first 3 seconds first. Ask for alternate hooks if it is not landing.
4. Fix any wrong caption words by timestamp.
5. Export 9:16 at 1080x1920 and post.

## What Vyra does that matters for you

- Word-by-word captions with emphasis words you name ("make 'never' bigger and yellow").
- Hook variations from the same timeline, so you can test openers without re-editing.
- Reference matching for trends: attach the trend video and say what to copy.
- Filler and pause removal with thresholds you set, which is the difference between crisp and robotic.

## What it does not do

- It does not pull sounds from TikTok. Upload the audio you have rights to use.
- It does not post for you.

## FAQ

**Can it keep captions out of the TikTok UI zones?**
Yes. Say "keep captions above the bottom 20 percent and away from the right edge" and it will respect the safe zone.

**Does it add automatic zooms?**
Only if you ask. If you want none, say "straight cuts only."

**Can it batch several videos with the same style?**
Yes. Set the style once, then say "apply the same caption and cut style to the other three clips."
