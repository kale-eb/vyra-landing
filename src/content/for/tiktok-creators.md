**TikTok rewards volume and a strong first two seconds. Vyra gets you from raw clips to a captioned vertical cut in a few prompts, and lets you try five versions of the hook without rebuilding the edit.**

## What you make

- [Talking head](/formats/talking-head) with word-by-word captions

## Your three most-used prompts

**Talking head cut**
```
Cut this into a 30-second 9:16 TikTok. Start on the line "nobody warns you about this", cut every pause over 0.4 seconds, filler words, and restarts. Word-by-word captions, bold white, slightly above center so they clear the bottom UI. No zooms or transitions.
```

**Hook variations**
```
Make three versions of this edit that only differ in the first 3 seconds. One opens on the reveal shot, one on me saying the punchline, one on a text hook that says "I was wrong about this". Same everything else.
```

**Trend recreation**
```
Match the attached reference. Same cut timing to the sound, same caption placement, same text style. Use my clips only, keep my order.
```

## A typical workflow

1. Upload the clips and the sound if you're using one.
2. Ask for the cut with the hook line, the length, and the caption style in one message.
3. Check the first 3 seconds first. Ask for other hooks if it isn't landing.
4. Fix wrong caption words by timestamp.
5. Export 9:16 at 1080x1920 and post.

## What Vyra does that matters for you

- Word-by-word captions with emphasis words you name. "Make never bigger and yellow."
- Hook variations from the same timeline, so you can test openers without re-editing.
- Reference matching for trends. Attach the trend video and say what to copy.
- Filler and pause removal with thresholds you set. That's the difference between crisp and robotic.

## What it does not do

- It doesn't pull sounds from TikTok. Upload audio you have rights to.
- It doesn't post for you.

## FAQ

**Can it keep captions out of the TikTok UI zones?**
Yes. Say "keep captions above the bottom 20 percent and away from the right edge."

**Does it add automatic zooms?**
Only if you ask. Say "straight cuts only" if you want none.

**Can it batch several videos with the same style?**
Yes. Set the style once, then say "same caption and cut style on the other three clips."
