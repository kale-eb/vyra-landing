**Agency editing is the same problem repeated across clients: a locked style, a pile of raw footage, and a deliverables list with deadlines. Vyra edits real footage from a written brief, holds each client's caption, title, and logo rules across cuts, and lets a junior editor produce a first pass that a senior finishes in the timeline. One editor, more accounts, less drift.**

## Your three most-used prompts

Style lock:
```
This client's style: captions in Montserrat Black, white with a thin black outline, 3-4 words per line, lower third. Logo top left at 8% width for the whole video. Music never above 25% under speech. Titles in their navy, hex 1B2A4A. Apply this to every cut in this project unless I say otherwise.
```

Deliverables batch:
```
From the interview: one 60-second 9:16 cut of the strongest answer, one 30-second cut of the customer result, and one 15-second hook clip from the line "we doubled it in a quarter". Same style. List the timestamps you used for each.
```

Revision from client notes:
```
Client feedback on cut 2: move the logo to top right, shorten the intro by 3 seconds, and swap the b-roll at 0:18 for the warehouse shot. Nothing else changes. Show me a frame at 0:18 when done.
```

## A typical workflow

1. Create one project per client. Upload the footage, logo, fonts, and a reference video of their look.
2. Write the style lock prompt once. Every later prompt inherits it.
3. Describe the deliverables list, one cut per message. Ask for timestamps so QA is fast.
4. Paste client revision notes as a prompt. One change per message when notes conflict.
5. Senior editor opens the timeline for final polish. Export per platform.

## What Vyra does that matters for you

- Style by description per project, so a client's look does not depend on which editor is on shift.
- Reference matching from a client's best-performing video: pacing, captions, music behavior, color.
- Transcript and scene search across a shoot: "every time the founder says 'pricing'."
- Timestamped change lists on request, which turns client QA into a two-minute check.
- MCP plans from $24/mo per seat if your team already runs on Claude or ChatGPT; Pro tiers export 4K.

## What it does not do

- It does not generate footage, avatars, or stock. Shoot or license the material.
- It does not manage client approvals or scheduling. Export and use your review tool.

## FAQ

**Can two editors work on the same client project?**
Both can open the same project in the browser against the same assets. Agree who owns which cut to avoid overwriting.

**Will the agent follow brand rules across every cut?**
State them once as a style lock at the top of the project and repeat "same style" on each cut. Check one frame per deliverable.

**Can we deliver 4K?**
Yes, on Pro tiers. Starter tiers export up to 1440p.
