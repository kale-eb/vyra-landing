An export preset is a bundled resolution, bitrate, and format choice matched to a destination so you do not set them by hand each time.
**Example.** 1080p at 20 Mbps MP4 for a Reel; 720p at 5 Mbps for a quick review file.
**In Vyra.** presets are Instagram / TikTok, YouTube Shorts, High Quality, Balanced, Small File, and Custom; each shows an estimated file size.
