A proxy file is a smaller, lower-resolution copy of a source clip used for smooth playback while editing, with the original swapped back in for export.
**Example.** a 4K phone clip plays as a 720p stand-in on the timeline so scrubbing does not stutter.
**In Vyra.** every upload gets a 720p proxy automatically, and export always uses the original file, never the proxy.
