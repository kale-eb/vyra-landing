In Vyra, a style is the visual identity applied to a project, covering the caption face, title face, accent face, and color palette.
**Example.** Vyra Default uses Inter Bold for captions and Montserrat Black for titles; Cinematic Film shifts type and color toward a filmic look.
**In Vyra.** choose a style when creating a project, or ask the agent to switch it mid-edit; templates set structure, styles set look.
