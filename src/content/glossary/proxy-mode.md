Proxy mode is an editor setting that plays lightweight proxy copies instead of full-resolution originals so the timeline stays responsive.
**Example.** scrubbing a 4K project feels instant because the editor is reading 720p stand-ins.
**In Vyra.** proxy mode is on by default; exports always render from the originals, so quality is never affected.
