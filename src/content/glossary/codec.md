A codec is the compression scheme that encodes video or audio into a file and decodes it for playback, separate from the container it lives in.
**Example.** an MP4 container can hold H.264 or HEVC video; the codec decides file size and compatibility, not the .mp4 extension.
**In Vyra.** exports use H.264 in MP4 for the widest compatibility, or VP8 in WebM for web delivery.
