**If your exported video has no sound, compare the original clip, your Vyra project preview and the saved file at the same moment. Check playback volume first. If the preview has the expected audio but the saved file does not, report that difference before rebuilding the edit.**

Missing speech and missing music are different clues. Note whether the whole video is silent, one section is silent or only one audio source is missing.

## Locate the difference

| Original | Preview | Saved file | What to check |
| --- | --- | --- | --- |
| Silent | Silent | Silent | Confirm that the original contains the sound you expected |
| Has sound | Silent | Silent | Inspect audio choices in the edit |
| Has sound | Has sound | Silent | Confirm you opened the latest file, then report the export difference |
| Has sound | Has sound | Has sound | Check the player or destination where sound seems missing |

The table helps narrow the question. It does not establish a cause for every silent export.

## Check the edit without changing everything

1. Turn up playback volume and check whether sound is going to headphones or another connected device.
2. Play the original clip at a moment with clear speech or music.
3. Play that same moment in the project preview. Check whether the intended audio is present and whether you muted or lowered it while editing.
4. Open the latest exported file directly, before judging the version posted elsewhere. Compare the same moment again.
5. If only the export is wrong, keep the project and contact [support](/app-support). Include the approximate timestamp and which audio is missing.

If the preview itself is too quiet, adjust the intended source and listen again. The [iPhone volume guide](/how-to/adjust-video-volume-on-iphone) explains balancing original sound and music. Avoid replacing your voice with a new recording merely to work around an unexplained export problem.

## A specific correction to ask for

Use this only if the edit's audio choices are wrong in the preview.

```
Keep my original speech audible throughout. Lower the music while I talk. Leave the clip order, captions and timing unchanged. Show me the section from 0:12 to 0:18 so I can check the balance.
```

## FAQ

**Can a video look finished and still have an audio problem?**
Yes. Play the actual exported file with sound before posting. Check the beginning, the ending and any section where the audio changes.

**Should I remove the music track?**
First check whether speech is missing or simply covered by music. If speech is too quiet in the preview, adjust the balance. If the preview is correct and the file is wrong, report the difference.

**How do I check a silent section?**
Note the start and end of that section. Compare it with the same section in the preview and original footage, then send support that narrow description.

**Will exporting again fix the sound?**
There is no guarantee. If you make another attempt, open the new file and compare the same moment. Repeated failures need investigation rather than repeated exports.

**How do I check sound that disappears after posting?**
Check the destination's playback and posting options. The working saved file is useful evidence that the difference appeared after that file was created.
