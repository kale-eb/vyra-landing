**Vyra’s current API documentation says any Vyra account can use the API and pay for videos from a funded balance. API payment is documented separately from the web editor’s subscription and trial.**

Choose the workflow before comparing its payment terms. A phone subscription, a web editor trial and an application submitting API jobs are different starting points.

## Follow the API access instructions

The [official API access section](/docs/api#get-a-key) explains creating a key in Settings and Developer. The [balance section](/docs/api#balance) documents paying from funds added there. Read the current charges and limits before deciding whether the workflow fits your application.

| Your goal | Appropriate information |
| --- | --- |
| Make an application submit editing jobs | API access, balance, prices and limits |
| Edit through the web interface | Web editor plans and trial |
| Edit from the native iPhone app | App Store plan and export limits |

## Check the cost of the actual job

Start your planning with the footage length and the kind of result you need. Confirm the current [API prices](/docs/api#prices) rather than assuming that an app credit or an earlier example establishes your API allowance.

A brief for a first planned job might be this.

> Edit my supplied clips into a short demo. Keep the spoken explanation, caption it and finish on the actual product result.

This is an example brief, not a submitted or charged job. Use the documentation to review access and costs before making requests.

## FAQ

**Does an iPhone subscription establish a free API allowance?**
No such allowance is established by the app plan. Check the API’s own documented balance, charges and any eligibility terms.

**Do I need Claude or ChatGPT to use the API?**
No. The API is for an application submitting jobs. MCP is the separate integration for assistants directing editing tools.
