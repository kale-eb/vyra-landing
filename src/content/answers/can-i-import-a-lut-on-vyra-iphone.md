**Vyra’s current help says custom .cube LUT import is available on the web, not directly in the iPhone or Android app. A LUT added to the project on the web still appears and exports from the iPhone app.**

You might have a .cube file and see a Style tab on your phone, then spend time looking for an import button. Use the documented web import for that file. The phone still has other color controls for a normal adjustment.

## Use the documented route for a .cube file

[Open Vyra’s web editor](https://app.usevyra.com) for a custom file. The current help section Color and the Adjust panel documents selecting the clip on the web, opening Adjust and Style, then using Load .cube LUT. Review the look on the footage before judging it from the file name.

When you open the project on iPhone, check the picture and saved export. Web access and its plan terms are separate from an iPhone subscription. The web app has a three-day trial and no ongoing free tier.

## Use native color adjustments when a LUT is unnecessary

On iPhone, the same help documents the Adjust tabs, including WB, HSL, Style, Wheels and Curves. A color cast or over-bright window may need a small targeted correction rather than an imported look. The [official iPhone listing](https://apps.apple.com/us/app/vyra-ai-video-editor/id6808889012) supports the native timeline workflow. New iPhone accounts receive 100 free credits. Free iPhone exports are 720p with a watermark. Check the App Store’s Plus and Pro options for paid limits.

## FAQ

**Does the iPhone Style tab mean .cube import is supported there?**
No. The current Vyra help explicitly limits custom LUT import to the web. Use native adjustments or the documented web import for the file.

**Does a LUT added on the web disappear on iPhone?**
Vyra’s help says a web-added LUT still shows and exports from the iPhone app. Review the actual project and exported file to confirm the intended result.
