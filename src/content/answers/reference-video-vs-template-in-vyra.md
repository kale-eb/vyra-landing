**Use a reference video when you want Vyra to analyze an example’s pacing, sections and look. Use a template when you want an established set of style choices, such as fonts, captions, colors, graphics and structure.**

You may like the rhythm of one Reel while already having a caption style you use in every video. Describe which part should come from each input so the result stays connected to your own footage.

## Choose the input that explains your goal

| Goal | Useful starting point |
| --- | --- |
| Follow the pacing of a particular example | A reference video with a clear instruction |
| Keep established styling across a series | A template that fits the work |
| Follow an example while retaining selected brand choices | State those choices separately and review the result |

Vyra’s current Templates help describes the styling a template supplies. Reference videos help describes analyzing sections, pacing, techniques and look. On iPhone, the Templates area contains both References and Templates.

## Give the example a specific role

Try a brief that names what belongs to the reference and what should stay yours.

> Follow the reference’s order of a result shot, the process and the result again. Keep my own caption font and original voice. Use only the footage I supplied.

The [official iPhone listing](https://apps.apple.com/us/app/vyra-ai-video-editor/id6808889012) documents starting from templates and saving references. Neither input guarantees that every shot in an example can be reproduced from different source material. Review missing context before changing effects. New iPhone accounts receive 100 free credits. ## FAQ

**Is attaching a reference the same as importing its footage into my edit?**
Specify the role of the video. Vyra’s help distinguishes using a link as reference from using it as footage. For your own edit, identify your supplied clips explicitly.

**Can a template decide which parts of the story matter?**
A template supplies style and structure. Describe the important action, spoken line and ending from your own footage so the edit has the needed context.
