**If a reference video will not open in Vyra, check whether you can still open it at its original location and whether it reached the intended project. If the reference opens but the edit looks wrong, describe the style mismatch separately.**

An unavailable reference and a reference followed too broadly need different next steps. Keep your own footage and current edit while you work out which one happened.

## Check where the handoff stopped

| What happened | Next check |
| --- | --- |
| The original post or file will not open | Confirm you still have access before trying to use it as a reference |
| Sharing appeared to finish but nothing is in the project | Check the project or saved reference you intended to use |
| A reference is present but an error appears | Record the message and ask support before repeatedly adding it |
| The reference opens but the edit misses its style | Name one visible property you wanted to follow |

Being able to watch a video in another app does not guarantee that every sharing route will accept it. Keep any visible error rather than assuming why access failed. Do not try to bypass another person's access restrictions.

## On iPhone

The documented workflow lets you share an Instagram Reel or TikTok to Vyra, then save the reference or start a project from it. Check which destination you selected before looking for the reference in an existing edit.

If Vyra does not appear in the share sheet, check its list of apps and confirm Vyra is installed. Sharing options belong to the source app and can change. See the full [iPhone reference walkthrough](/how-to/match-a-reference-video-on-iphone) for the ordinary steps.

## If the reference opens but the result is wrong

Ask Vyra to describe the reference before making another edit. Then name the particular quality you want, such as caption placement or the order of hook, process and result. Review one change before asking for the rest.

```
Use the attached reference only for caption placement. Keep my footage, audio and clip order. First describe where the reference puts its captions so I can confirm that is the part I mean.
```

If the description does not match what you see, point out the difference. Exact reproduction of every effect is not guaranteed.

## FAQ

**Can I share a Reel or TikTok to Vyra on iPhone?**
Yes. Caleb's mobile release post describes sharing from both apps, then saving a reference or starting a project from it.

**Why is the reference missing from my current project?**
Check whether you saved it as a reference or started a different project during sharing. If you cannot locate it, describe the source and sharing steps to support without posting private material publicly.

**Can I use a private video?**
You need appropriate access and permission to use it. We cannot promise that every private post or restricted link will work as a reference. Do not bypass access restrictions.

**Should I add the reference as footage instead?**
Keep the roles clear. Your footage is what you want edited; a reference guides the editing choices. Follow the reference workflow rather than adding someone else's footage to the finished video by accident.

**What should I send support?**
Say which app or file you started from, whether it still opens there, where you expected it to appear and any visible error. Ask support for a private way to share further material if needed.
