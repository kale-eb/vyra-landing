**Camera roll to posted Reel without an evening in a timeline. Vyra does the cut, captions, and music from a description of what you want, then exports a vertical file and a square one for the grid if you ask.**

## How it works

1. Upload the clips and any music you have rights to.
2. Describe the Reel. Format, length, hook, what to keep and cut, caption style, music level.
3. The agent puts it together and keeps captions inside the safe zone.
4. Ask for a grid version if you want the same edit at 1:1.
5. Export with the Instagram/TikTok preset.

## What you can control

| Setting | Options |
| --- | --- |
| Aspect | 9:16 for Reels, 1:1 or 4:5 for the grid |
| Hook | A quoted line or a described shot first |
| Captions | Phrase, word-by-word, or highlight, with emphasis words bigger |
| Music | Uploaded track, cuts on the beat, ducking under speech |
| Text | Titles, lower thirds, motion graphics from a prompt |
| Look | Effects by category, reference style matching |

## Prompts to paste

```
Cut a 40-second Reel about my studio setup. Open on the wide shot of the room, then one clip per corner as I mention it, captions in 3 to 5 word phrases, lo-fi track at 25 percent under my voice.
```

```
Make a 1:1 version of this Reel for the grid with my face centered. Keep everything else the same.
```

```
Add a lower third with @sulansart for the first 4 seconds, bottom left, simple slide in.
```

## When to use something else

- You want Instagram's native templates, filters, and audio library. Instagram's own editor and CapCut have those.
- You edit only on a phone. Vyra runs in the browser.
- You need it scheduled and posted from the tool. Vyra exports files.

## FAQ

**Which export for Reels?**
The Instagram/TikTok preset. 1080p vertical MP4 at 20 Mbps.

**Can I get a grid crop of the same edit?**
Yes. Ask for 1:1 with the subject centered.

**Do captions stay clear of the Reels overlay?**
Ask for the lower third above the bottom safe area.
