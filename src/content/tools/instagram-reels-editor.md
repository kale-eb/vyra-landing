**A Reels editor should get you from a camera roll to a posted clip without an evening in a timeline. Vyra does the cut, captions, and music from a description of the Reel you want, then exports a vertical file and, if you ask, a square one for the grid.**

## How it works

1. Upload the clips and any music you have rights to.
2. Describe the Reel: format, length, hook, what to keep and cut, caption style, music level.
3. The agent assembles it and captions it inside the safe zone.
4. Ask for a grid version if you want the same edit at 1:1 with the subject centered.
5. Export with the Instagram/TikTok preset.

## What you can control

| Setting | Options |
| --- | --- |
| Aspect | 9:16 for Reels, 1:1 or 4:5 for the grid |
| Hook | Quoted line or described shot first |
| Captions | Phrase, word-by-word, or highlight; emphasis words enlarged |
| Music | Uploaded track, beat-synced cuts, ducking under speech |
| Text | Titles, lower thirds, motion graphics from a prompt |
| Look | Effects by category, reference style matching |

## Prompts to paste

```
Cut a 40-second Reel about my studio setup. Open on the wide shot of the room, then one clip per corner as I mention it, captions in 3 to 5 word phrases, lo-fi track at 25 percent under my voice.
```

```
Make a 1:1 version of this Reel for the grid with my face centered. Keep everything else the same.
```

```
Add a lower third with @sulansart for the first 4 seconds, bottom left, simple slide in.
```

## When to use something else

- You want Instagram's native templates, filters, and in-app audio library. Instagram's own editor and CapCut cover that.
- You edit only on a phone. Vyra runs in the browser.
- You need the Reel scheduled and posted from the tool. Vyra exports files.

## FAQ

**Which export should I use for Reels?**
The Instagram/TikTok preset: 1080p vertical MP4 at 20 Mbps.

**Can I get a grid crop of the same edit?**
Yes. Ask for a 1:1 version with the subject centered, and the agent reframes with masks.

**Do captions stay clear of the Reels overlay?**
Ask for the lower third above the bottom safe area and the agent keeps them there.

**Can Claude or ChatGPT edit my Reels?**
Yes. Over MCP the assistant has the same editing and export tools.
