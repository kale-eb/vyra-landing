**An app walkthrough is a screen recording of a real task inside an app, with the creator's face in a corner or split frame narrating each step so the viewer can follow along and copy it.**

## At a glance

| | |
| --- | --- |
| Best for | SaaS tutorials, launch videos, "how I use X" content, vibe-coding builds |
| Hook style | Face to camera: "here's how I do X in 30 seconds" |
| Pacing | 3-5 seconds per step, zoom on each click |
| Caption style | Phrase captions in the face section, step labels in the screen section |
| Music | Light bed or none |
| Shot list | Screen recording of the task. Face recording, synced. Final result. Optional b-roll of the output. |
| Common mistakes | Face too big or too small. Screen unreadable at phone size. Narration lags the click. |

## Structure

- 0-3s: face, the promise
- 3-8s: the starting screen, what we're working with
- 8-60s: steps, screen zoomed on each action, face in corner
- 60-75s: the result
- 75-85s: face, one tip or where to find it

## How to shoot it

- Record screen and face at the same time so they stay synced.
- Face: eye level, small light, plain background.
- Screen: increase UI zoom to 125-150% before recording so text reads on a phone.
- Move deliberately. Pause half a second after each click.
- Say the step name as you do it.

## How to edit it

- Layout: screen top 65%, face bottom 35%, or face as a circle in a corner.
- Zoom the screen into each action region.
- Cut out every pause between steps.
- Step label on the screen half, captions on the face half.
- Speed up typing and loading.
- Hold the final result 3 seconds full frame.

## Prompt it in Vyra

> Combine my screen recording and my face recording into a vertical walkthrough, screen on top and my face on the bottom third. Cut it to 60 seconds, remove pauses, and zoom into the part of the screen I'm clicking on for each step. Add a step label at the top when I say "step one", "step two" and so on.

> Reframe the screen recording so the cursor is always in view and the text is readable on a phone.

> Show the final dashboard full frame for the last 3 seconds and put my face back on for the last line.

## Variations

- Face-free walkthrough: screen only, voiceover, labels.
- Build-in-public walkthrough: what you shipped this week.
- Speed run: entire task in 15 seconds, no narration.
- Side-by-side: two apps doing the same task.

## FAQ

**Face in corner or split?**
Split for tutorials where the face adds trust. Corner circle for fast tips where the screen needs space.

**How do I keep the screen readable vertically?**
Zoom the UI before recording and let the edit crop around the cursor. Never shrink a full desktop into a vertical frame.

**Can Vyra combine screen and face recordings?**
Yes. Ask for a layout by describing it, and it syncs both sources on the timeline.
