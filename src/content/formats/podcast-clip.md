**A podcast clip is a self-contained 30-90 second moment cut from a longer conversation, reframed vertical, captioned, and opened on the most quotable line.**

## At a glance

| | |
| --- | --- |
| Best for | Growing a podcast, repurposing long interviews, guest promotion |
| Hook style | The punchline first, then the setup |
| Pacing | Speaker switches on every reply, punch-ins on emphasis |
| Caption style | Word-by-word with speaker color or 3-5 word phrases |
| Music | None, the conversation is the sound |
| Shot list | Wide two-shot. Single on each speaker. A screen recording of the episode title for the end card. |
| Common mistakes | Starting the clip at the question instead of the answer. Long clips that need context the viewer doesn't have. Static wide shot for 60 seconds. |

## Structure

- 0-3s: the quotable line, captioned large
- 3-10s: the question that led there, if needed
- 10-60s: the full answer, cut to the active speaker
- 60-70s: reaction or follow-up from the host
- 70-75s: end card with the episode name

## How to shoot it

- Record each speaker on their own camera in 4K so you can reframe to vertical.
- Frame each person centered with headroom, so a 9:16 crop keeps the whole face.
- Record separate audio tracks per speaker.
- Mark timestamps of good moments during recording. It saves an hour later.
- Keep lighting consistent across both speakers.

## How to edit it

- Find the line that works with zero context. Start there.
- Reframe to vertical on the active speaker, switching on every turn.
- Cut filler words and cross-talk aggressively.
- Add captions with a subtle color change per speaker.
- Punch in 10-15% on the strongest sentence.
- End card: episode title, where to listen, 3 seconds.

## Prompt it in Vyra

> Find the 5 most quotable 45-60 second moments in this 90-minute podcast, the ones that make sense without context. Cut each one vertical, framed on whoever is speaking, with captions colored by speaker. Start each clip on the strongest line.

> Cut the section where we talk about "burnout" into a 60-second Reel. Open on the guest's line about "the calendar was full but I was empty", then cut back to the question. Punch in on that line.

> Match the layout and caption look of the attached reference clip for all five clips.

## Variations

- Single-speaker clip: only the guest, host cut entirely.
- Stacked layout: both speakers visible, top and bottom.
- Audiogram: a still photo with a waveform, for audio-only shows.
- Chaptered clip: three short answers strung together with title cards.

## FAQ

**How do I choose which moment to clip?**
Pick lines that are surprising, specific, or emotional and that stand alone. If the clip needs the previous 5 minutes, skip it.

**Can Vyra find the moments for me?**
Yes. It transcribes the whole episode, so you can ask for moments by topic, by keyword, or by "most quotable".

**Should podcast clips have music?**
Rarely. The conversation carries it. Add a bed only if the room audio is thin.
