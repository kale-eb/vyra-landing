**ChatCut and Vyra both let you edit real footage by chatting, including from Claude Code or the ChatGPT app. Vyra adds per-scene visual analysis, a built-in AI option, reference matching, and a full browser timeline. ChatCut is the lighter, more developer-flavored one.**

This is a close comparison. Both products start from the same idea, that the editor should take instructions instead of clicks. ChatCut is a chat-driven editor you can also run from the ChatGPT desktop app and Claude Code. Vyra runs in the browser with its own agent chat, and over MCP from Claude, ChatGPT, or Cursor. The differences are what the agent knows about your footage and how far the editor goes after the first cut.

## Where ChatCut is stronger

- Plugins for both ChatGPT desktop and Claude Code.
- A good fit if you already work inside those apps all day.
- Simpler if you never plan to touch a timeline.

## Where Vyra is stronger

- Visual understanding. Every scene is described on upload, so "the shot where I hold up the finished piece" works without a transcript.
- Two ways in. Built-in agent chat if you have no AI subscription, MCP if you do.
- Reference video matching and custom motion graphics from a description.
- A full timeline for the last bit. Masks, keyframes, effects, multi-track audio.

## Choose Vyra if

- Your footage has visual moments the transcript will not find.
- You want a built-in AI with no external account.
- You want to copy the pacing and captions of a video you like.

## Choose ChatCut if

- You already edit inside ChatGPT or Claude Code and want the lightest tool.
- Your content is talk-first and transcript search is enough.
- You want to try chat editing free before paying for anything.

## Try the same edit in both

Same task for both. A 45-second studio vlog cut from 8 minutes with one b-roll insert.

The first message is similar in both:
```
Cut this 8-minute studio vlog to 45 seconds for Reels. Open on the shot where the canvas comes out of the box, then the three best painting moments, then me holding up the finished piece. Cut all talking except "this is the part everyone skips". Phrase captions, white, lower third. Calm piano under it at 25%.
```

Vyra finds "the shot where the canvas comes out of the box" from its scene descriptions. A transcript-led agent needs you to describe it by what was said.

## FAQ

**Can both be used from Claude Code?**
Yes. ChatCut supports Claude Code directly. Vyra connects to Claude Code, Claude Desktop, and claude.ai over MCP.

**Which is better for a developer building a video pipeline?**
Either can be scripted through an assistant. Vyra also connects to Cursor and gives the agent the full tool set.

**Which is cheaper?**
ChatCut pricing is on its site. Vyra starts at $24/mo and is free to start.
