**VEED is a simple browser editor for subtitles and trims, with AI avatars and generated clips on the side. Vyra is a browser editor where an AI edits your real footage from a description.**

Both run in a browser tab. The difference is what the AI is allowed to do. VEED's AI helps with subtitles, background removal, avatars, and short synthetic clips. It does not make cuts in your footage. Vyra's AI reads the transcript and every scene, then builds the edit.

## At a glance

| | VEED | Vyra |
| --- | --- | --- |
| Edits your real footage | Yes, manual | Yes, agent-driven |
| Edit by chat / natural language | No | Yes, built-in chat |
| Bring your own AI (MCP: Claude, ChatGPT, Cursor) | MCP exists, generates clips only | Yes, full editing tools |
| Understands footage (transcript + scene analysis) | Transcript for subtitles only | Transcript plus scene analysis |
| Captions | Yes, strong auto-subtitles | Yes, word-by-word or phrases |

| Manual timeline | Yes, browser | Yes, full editor |
| Export cap | 720p free, 1080p to 4K paid | 1440p (AI Starter), 4K (AI Pro) |
| Platform | Browser | Browser |
| Best for | Quick subtitle and trim jobs, AI avatars | AI-edited real footage |

## Where VEED is stronger

- AI avatars. If you need a synthetic presenter, VEED has one.
- Text-to-video generation with its Fabric model.
- Very easy for a first-time editor doing a trim and subtitles.

## Where Vyra is stronger

- The agent edits. VEED's MCP only generates new clips. Vyra's MCP gives Claude or ChatGPT the timeline.
- Motion graphics beyond fade, slide, and bounce. Describe a lower third and it gets built.
- Reference matching. Show a video, get its pacing and text style applied to yours.

## Choose Vyra if

- You have real footage and want it edited.
- You want more than preset text animations.
- You want to use the AI subscription you already have.

## Choose VEED if

- You need an AI avatar or a generated clip.
- The job is subtitles plus a trim.
- You want the simplest possible UI.

## Try the same edit in both

Same task for both. Subtitle a 3-minute clip and cut it down to 60 seconds.

In VEED you run auto-subtitles, then split and delete sections on the timeline by hand.

In Vyra:
```
Cut this to the best 60 seconds. Keep the intro line and the demo, drop the tangent about pricing. Add phrase captions, white with a thin black outline, lower third. Straight cuts, no transitions.
```

## FAQ

**Does VEED's MCP let AI agents edit video?**
No. It connects to VEED's generative model to make short synthetic clips. It does not expose the editor.

**Can VEED see what is in my video?**
It detects faces for background removal and eye contact, and transcribes audio. It does not describe scenes.

**Which has better captions?**
Both auto-caption well. In Vyra you can set grouping, emphasis words, and placement in plain language, or copy a reference video's caption style.
