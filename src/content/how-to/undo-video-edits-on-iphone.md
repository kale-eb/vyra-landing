**To undo an edit in Vyra on iPhone, use Undo for a recent change or open History to return to an earlier saved version of the project.**

You asked for a shorter opening and now the line you liked is gone. Stop making changes for a moment. Decide whether you want to reverse the last action or recover a version from before several changes.

Version 0.1.8 documents the clock button and earlier saves. Version 0.1.5 documents Undo in the editor. See the [official Vyra App Store listing and version history](https://apps.apple.com/us/app/vyra-ai-video-editor/id6808889012).

## Work through the edit

1. Open the project that contains the change you want to reverse.
2. Use Undo when you want to step back from a recent action.
3. For an earlier saved version, open History from the clock button.
4. Choose the save you need and play the section you were trying to recover.
5. Check the rest of the timeline before continuing or exporting another copy.

## Make the important choices

| What you find | Editing choice |
| --- | --- |
| One recent mistake | Try Undo before making more changes |
| Several changes since the preferred edit | Look for the earlier save in History |
| A change only visible in an exported file | Return to the editable project before revising |

## A brief to try

```
I want to keep the earlier opening where I finish the sentence about my first painting. Help me identify that section before making any new cuts. Leave the rest of the edit alone.
```

Listen for the recovered sentence and check its neighboring clips. Returning to a save may also return other parts of the project to their earlier state. Write down any later changes you still want to keep so you can make them again deliberately.

## FAQ

**Does History contain every individual action?**
The release notes describe earlier project saves. Do not assume every action creates a separate save.

**Will Undo change a video I already posted?**
Undo changes the project. Export a revised file and update your post separately if needed.

**Should I delete the project and start over?**
Check Undo and History first. Deleting the project removes the place where you would review those versions.
