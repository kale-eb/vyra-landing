**To combine two reference styles in Vyra on iPhone, assign each reference one clear role and tell the app which rule wins when the examples conflict.**

One example has the opening you like. Another has captions you can read. Asking for both entire styles can produce mixed instructions about pace, colors and sound. Keep only the useful part of each.

Caleb documents saving shared references, and the native listing describes reference-guided editing. The role-and-priority method is a suggested brief, not a product test. See the [official Vyra App Store listing and release notes](https://apps.apple.com/us/app/vyra-ai-video-editor/id6808889012).

## Work through the edit

1. Share the main reference through the documented workflow and write down the useful detail from the second example.
2. In the brief, label the first example as structure and describe the second example’s caption placement.
3. Write the parts of each example that should be ignored.
4. Give a priority rule for conflicts and request a draft using your footage.
5. Compare structure and captions separately before asking for another change.

## Make the important choices

| Situation | What to check |
| --- | --- |
| References use different music | Choose your own audio instruction |
| Caption placement covers your subject | Let your footage’s visibility take priority |
| Both references define the opening | Choose one opening structure before editing |

## A brief to try

```
Use my shared reference only for opening structure. For captions, follow this description from my second example. Use short lines above the hands, with a readable size. Keep my existing music and story order.
```

## Check the result

Keep a note of which example governs each decision. If a draft goes wrong, point to the specific rule instead of asking it to become “more like both.” Start with one reference if two are making the brief harder to understand.

## FAQ

**Do I have to attach both examples to the same project?**
Share the main reference and describe the useful detail from the second in words. Give each example a clear role in the brief.

**Is exact reproduction guaranteed?**
No. The references guide an edit using your material; particular effects or missing shots may not transfer.

**Can I change one borrowed property later?**
Ask for that property specifically and identify the choices you want preserved. Review the revised draft.
