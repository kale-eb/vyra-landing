**To give several clips a shared effect in Vyra on iPhone, use an adjustment layer over the section that should change. Check its duration and what sits beneath it.**

You want the middle of a travel recap to look consistent, but the opening should keep its original color. Set the affected section first. A shared adjustment is easier to judge when you know exactly where it starts and stops.

Version 0.1.7 introduces adjustment layers and explains that they affect material beneath them. See the [official Vyra App Store listing and version history](https://apps.apple.com/us/app/vyra-ai-video-editor/id6808889012).

## Work through the edit

1. Choose the section of the timeline that should share the effect.
2. Add an adjustment layer above the intended clips.
3. Set its start and end around that section.
4. Apply the adjustment and inspect each clip beneath the layer.
5. Check the first and last affected frames, then review any titles before export.

## Make the important choices

| What you find | Editing choice |
| --- | --- |
| Several neighboring clips need one look | Cover their section with the shared layer |
| One clip is already much darker | Judge that clip separately before applying more |
| A title changes unexpectedly | Inspect whether it sits beneath the adjustment layer |

## A brief to try

```
Give the studio montage a consistent warm look. Keep the introduction unchanged. Show me where the adjustment starts and ends, and check that the white title is still readable.
```

A layer can be correctly placed while the result still looks wrong on one shot. Compare a bright and a dark clip under the same adjustment. Reduce the effect or refine the affected section if one of them loses the detail you wanted to show.

## FAQ

**Does an adjustment layer affect everything below it?**
The release notes describe it as applying an effect or adjustment to everything beneath it. Check the track order and covered time.

**Should I apply the same strength to every shot?**
Use the same starting look, then review each shot. Different lighting can need different treatment.

**Can I limit the look to the montage?**
Set the adjustment layer to cover that section and check the frames on either side.
