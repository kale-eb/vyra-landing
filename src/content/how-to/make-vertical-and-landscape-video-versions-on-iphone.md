**To make vertical and landscape versions on iPhone, choose the framing separately for each layout and export each version after reviewing it. Changing the canvas alone does not check what the crop hides.**

A face near the edge of a wide shot may disappear in the vertical version. A title placed for a tall frame may look oddly small in a wide one. Write down the two destinations before changing the layout.

The listing confirms canvas choices and export. Version 0.1.8 documents export-size controls and project History. See the [official Vyra App Store listing and version history](https://apps.apple.com/us/app/vyra-ai-video-editor/id6808889012).

## Work through the edit

1. Finish the sequence and decide which version to prepare first.
2. Set that canvas and review the framing of every important shot.
3. Check text and captions, then export the first version.
4. Prepare the other layout and adjust framing and overlays for it.
5. Export the second file and open both to confirm the intended composition.

## Make the important choices

| What you find | Editing choice |
| --- | --- |
| A wide demonstration needs both hands visible | Keep the action visible in each layout |
| A title fills the tall frame | Recheck its size and position in landscape |
| One crop loses necessary detail | Use a wider composition for that shot rather than hiding the action |

## A brief to try

```
Prepare a vertical version for my Reel and a landscape version for the full demo. Keep the same explanation. Review the shots showing both hands and make sure every text label is readable in each version.
```

Check the delivered files side by side. Matching runtimes do not prove matching information. A crop can remove the button, ingredient or gesture that the voiceover names. Keep the original footage available while reviewing the second layout.

## FAQ

**Is resizing the same as reframing?**
Resizing changes the layout. Reframing decides which part of each shot remains visible.

**Should captions stay at identical coordinates?**
Place them where they are readable in each layout. The two frames have different available space.

**Do I need a particular duplicate-project button?**
This guide does not assume one. Export the first checked version before preparing the next and use History where needed.
