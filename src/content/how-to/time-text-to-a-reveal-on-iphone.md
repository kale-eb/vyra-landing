**In Vyra on iPhone, add the text and ask chat to start it at the moment the result becomes visible. Specify when the text should disappear so it does not cover the setup or the next section.**

A label saying finished arrives too early if the viewer is still watching the last coat dry. Tie the words to the visible change. Keep the result uncovered long enough that the viewer can see what the label describes.

The [official iPhone listing and release notes](https://apps.apple.com/us/app/vyra-ai-video-editor/id6808889012) document native editing. Vyra’s current in-app help section Getting the best AI results supports the controls or chat workflow below.

## Work through the edit

1. Find the first frame where the result is clearly visible.
2. Write the short label you want to show at that moment.
3. Ask Vyra to time the text’s appearance and disappearance.
4. Replay the approach to the reveal and check that the label does not arrive early.
5. Check text readability and the clean frame after it ends.

## A brief to try

> Show the text finished only when the completed shelf appears. Keep it away from the repaired corner and remove it before the next shot begins.

## Check the result

The App Store listing documents text editing, and Vyra’s help recommends timestamped text requests. If a later trim moves the reveal, review the label again. A text cue that was correct in the first draft may now point to the wrong shot.

New iPhone accounts receive 100 free credits. Free iPhone exports are 720p with a watermark. Check the App Store’s Plus and Pro options for paid limits.

## FAQ

**Should I give a timestamp or describe the reveal?**
Either can establish the intended moment. A timestamp is useful when several similar shots could match the description. Preview the selected moment afterwards.

**Do I need an animated title for this?**
A short static label may be enough. Choose animation only if it still leaves time to read the words and inspect the result.
