**To compare two video openings with Claude, give both versions the same main sequence and change only the opening. Ask Vyra to prepare separate projects or clearly identified versions, then review both exports.**

You have one opening that starts with the finished painting and another that starts with the problem. Keep the rest of the edit consistent so you can judge the difference. Changing the song, length and captions too makes the comparison harder to interpret.

Caleb documents project creation and multi-project work. The MCP docs support inspecting and editing the resulting timelines. See the [official MCP guide](https://www.usevyra.com/docs/mcp) and [Caleb’s headless-server post](https://www.usevyra.com/blog/vyra-mcp-v2).

## Work through the edit

1. Choose the approved main sequence and write what must stay the same.
2. Describe the two openings using footage you actually have.
3. Ask Claude to prepare separately identified Vyra versions and report what differs.
4. Review the opening and its join to the unchanged main sequence in each version.
5. Export and label both files before choosing or testing them.

## Make the important choices

| What you find | Editing choice |
| --- | --- |
| Opening A shows the result | Check that the following sequence still explains how it happened |
| Opening B starts with a spoken problem | Keep the complete line before the main sequence |
| One version also changes the music | Restore the agreed constraint before comparing |

## A brief to try

```
Prepare two clearly named versions of this edit. A opens on the finished painting. B opens on my line about the mistake. Keep the same main sequence, captions and music after the opening. Tell me what differs before exporting either version.
```

Check the end of the opening as carefully as its first frame. A new hook can create a repeated sentence or an unexplained jump into the body. These are creative alternatives, not evidence that one will get more views.

## FAQ

**Does this automatically run an audience test?**
No. It prepares alternatives. Publishing and measuring a controlled audience test is separate work.

**Can Vyra create more than one project through MCP?**
Caleb describes creating projects and working on several projects with the headless server.

**Should the openings use generated video?**
Use footage you supply for this workflow. Vyra does not generate video footage.
