**To change a video after exporting it on iPhone, reopen the editable Vyra project, make the revision and export a new file. Review the new copy before replacing the old one.**

An exported video is a finished copy. Your project is where the clips, captions and timing remain editable. Keep track of which one you are changing so you do not import a flattened export and expect all the original layers to return.

The listing confirms editable projects and export to Photos. Version 0.1.8 adds earlier project saves in History. See the [official Vyra App Store listing and version history](https://apps.apple.com/us/app/vyra-ai-video-editor/id6808889012).

## Work through the edit

1. Open the original Vyra project for the video.
2. Write the exact change and identify anything that must stay the same.
3. Revise the relevant clip, caption or audio section.
4. Preview the changed section and the beginning and end of the full edit.
5. Export a new copy and compare it with the earlier file before posting.

## Make the important choices

| What you find | Editing choice |
| --- | --- |
| A caption has a spelling error | Correct the caption in the project |
| Only the finished MP4 remains | Expect fewer editable parts than in the original project |
| The video is already online | Update the published post separately after making the new file |

## A brief to try

```
In this project, change the closing text to "See the full painting on my profile." Keep the clip order, music and opening unchanged. Show me the final section before exporting a new copy.
```

Check the filename or creation time when choosing the upload. It is easy to edit the right project and post the earlier export by mistake. Play the exact file you are about to share and confirm the revised line is present.

## Review and export

Open the saved export in Photos and check the actual file before posting. New mobile accounts currently get 100 free credits. Free exports are 720p with a watermark. Plus and Pro are sold through the App Store. AI features need an internet connection. Start with the [iPhone app guide](/ai-video-editor-app) for setup.

## FAQ

**Does a new export update my existing social post?**
No. You still need to manage the published post in that platform.

**Can an MP4 restore my original text layers?**
An exported file does not recreate the original project layers. Reopen the project when you have it.

**Should I keep the earlier export?**
Keep it until you have checked the revision. It gives you something concrete to compare.
