**In Vyra on iPhone, open the selected clip’s Adjust controls and HSL tab, or ask chat to change the intended color range. Review other objects that share that color before keeping the change.**

A green wall may be too vivid, but the leaves on the table use the same color range. A color-range adjustment can affect both. Check the whole frame instead of judging only the object you wanted to change.

The [official Vyra iPhone listing](https://apps.apple.com/us/app/vyra-ai-video-editor/id6808889012) documents editing your own footage. Vyra’s current in-app help, Color and the Adjust panel, supports the controls or chat workflow below.

## Work through the edit

1. Identify the color and the object you want to adjust.
2. Select the clip and open Adjust, then HSL.
3. Make a restrained change or describe the desired color-range change in chat.
4. Replay the clip and inspect other objects in the same range.
5. Compare against the original before applying the treatment elsewhere.

## A brief to try

> Reduce the vivid green in this shot slightly. Keep the leaves looking believable and preserve the red product label. Show me the change before applying it to other clips.

## Check the result

Vyra’s help describes HSL changes by hue, saturation and luminance for one color range at a time. A color range is not an object selection. If only one object should change, describe that requirement separately rather than assuming HSL isolates it.

## FAQ

**Will changing green affect only the wall?**
An HSL range can affect other green objects too. Inspect the leaves, clothes and reflections that share the selected range.

**Is HSL the same as white balance?**
White balance addresses the overall color cast. HSL adjusts selected color ranges. Start with the overall balance if the entire shot has an unwanted tint.
