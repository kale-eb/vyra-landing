**To add chapter cards in Vyra on iPhone, divide the video at meaningful topic changes and place a short text heading at each section boundary.**

A long explanation gets easier to follow when the viewer can tell that the next part has started. A chapter card should name the section they are about to watch. It does not need to repeat the entire introduction.

The native listing confirms text overlays and clip arrangement. Chapter selection and heading wording are editorial choices. See the [official Vyra App Store listing and release notes](https://apps.apple.com/us/app/vyra-ai-video-editor/id6808889012).

## Work through the edit

1. Finish the broad order of the video before adding headings.
2. Choose boundaries where the topic or stage actually changes.
3. Write a short, specific title for each section.
4. Add and time the text so it is readable without covering the first important action.
5. Watch every boundary and remove headings that interrupt a continuous thought.

## Make the important choices

| Situation | What to check |
| --- | --- |
| The same topic continues | Keep the section together |
| The process moves to a new stage | Add a heading that names the next task |
| A heading covers a key detail | Move its placement or give it separate reading time |

## A brief to try

```
Add short chapter headings for Preparation, Mixing and Final checks at the actual section boundaries. Keep the spoken edit and footage order unchanged. Leave the first useful action in each section visible.
```

## Check the result

Use the same wording in the heading and the explanation when possible. If a card says “Final checks” and the next minute is still preparation, move it. Chapter cards are part of the exported image; they are separate from a platform’s clickable chapter features.

## FAQ

**Will these become clickable YouTube chapters?**
Text inside the video does not by itself create clickable platform chapters. Set those up separately where supported.

**Do I need a blank screen behind each title?**
You can use available clear space or a deliberate card treatment. Check that the words remain readable.

**Should I add a card at every cut?**
Use meaningful section boundaries. Repeated headings can interrupt the explanation.
