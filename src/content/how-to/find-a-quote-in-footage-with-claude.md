**To find a quote in footage with Claude and Vyra, search the available transcript, return the source and time range, then verify the actual recording before using the excerpt.**

You remember someone saying the room felt different after the renovation. That memory may be a paraphrase. Ask for likely matches, then listen before putting quotation marks around the result.

The MCP docs explicitly support searching footage by transcript and browsing source assets. See the [official MCP documentation](https://www.usevyra.com/docs/mcp).

## Work through the edit

1. Connect Claude to the project containing the interview or recording.
2. Provide the remembered phrase and identify whether it is exact wording or a paraphrase.
3. Ask for candidate transcript matches with source names and time ranges.
4. Review the surrounding audio for wording, speaker and context.
5. Choose the verified excerpt before adding or replacing timeline material.

## Make the important choices

| Situation | What to check |
| --- | --- |
| An exact phrase is known | Search that wording first |
| Only the meaning is remembered | Request candidate matches and inspect them |
| Several similar statements exist | Compare the context before choosing |

## A brief to try

```
Find where the speaker describes the room feeling different after the renovation. That is my paraphrase, not a verified quote. Return candidate source time ranges and surrounding context. Do not edit the timeline yet.
```

## Check the result

Check the start and end of the excerpt as carefully as the memorable sentence. A nearby qualification can change its meaning. If the transcript and the sound disagree, use the recording to verify the words instead of treating search output as a finished quotation.

## FAQ

**Do transcript matches need a listening check?**
Verify the recording first, especially when the wording will be published as a quotation.

**Will a visual search find the same thing?**
Transcript search targets spoken material. Visual search answers a different question about what appears on screen.

**How do I handle a search with no match?**
Check the available assets and your remembered wording. An empty search does not establish that the sentence was never recorded.
